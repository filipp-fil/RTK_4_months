# RTK_4_months — учебный проект роботизированной ячейки

> 16-недельный самостоятельный учебный маршрут: CAD → ПЛК → симуляция робота → интеграция → документация.
> **Это учебный/симуляционный проект. Реальное промышленное оборудование не подключается.**

## 🎯 Цель проекта

К концу 16-й недели собрать учебный проект роботизированной ячейки, включающий:

- **CAD-модель** простого двухпальцевого захвата и деталей ячейки;
- **комплект чертежей** (деталь + сборка) с читаемыми размерами и единицами (мм);
- **логику последовательности ПЛК** (state machine: IDLE → WAIT_PART → LOAD → MACHINING → UNLOAD → COMPLETE / FAULT);
- **траекторию pick-and-place** в симуляции (точки HOME, APPROACH_PICK, PICK, LIFT, APPROACH_PLACE, PLACE, RETREAT);
- **тесты** штатных и аварийных сценариев;
- **документацию**: ТЗ, таблица I/O, схема обмена сигналами робот—ПЛК, матрица отказов, README.

## 📦 Что должно получиться (артефакты)

| Область      | Артефакты                                                               |
| ------------ | ----------------------------------------------------------------------- |
| Документация | ТЗ, блок-схема цикла, таблица I/O, диаграмма состояний, матрица отказов |
| CAD          | Нативные файлы, STEP, PDF-чертежи, перечень деталей                     |
| ПЛК          | Проект CODESYS (или Python-модель + псевдокод ST), коды ошибок          |
| Робот        | Таблица точек, сцена симуляции, скриншоты/видео                         |
| Тесты        | Таблицы тестов (штатные + аварийные), протоколы                         |
| Портфолио    | README, презентация 5–7 слайдов, демо-видео                             |
